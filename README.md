# PK Portfolio — Static HTML Version

This portfolio uses only:
- HTML
- CSS
- JavaScript

No Node.js, npm, React, or build tools are required.

## Run locally

1. Open the folder.
2. Double-click `index.html`.
3. The website opens in your browser.

## Customize before publishing

1. Open `index.html` in a text editor or VS Code.
2. Replace:
   - `your.email@example.com`
   - `https://www.linkedin.com/`
   - `https://github.com/`
   - project links marked with `href="#"`
3. Add your resume:
   - Create `assets/resume.pdf`
   - Put your PDF there.
4. Review all dates, project details, and achievement wording.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Open repository Settings.
4. Select Pages.
5. Under Build and deployment, choose:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
6. Save.
7. GitHub will provide a public website URL.

## Important

The starter content contains placeholders. Replace them with accurate details and working links before sharing the site with recruiters.
